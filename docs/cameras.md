# Подключение камер

## 1. Web-камера (USB, UVC)

Обычные веб-камеры (Logitech, Microsoft LifeCam, Defender, A4Tech и т.п.) и любые
UVC-совместимые устройства видны как `VideoCapture(0)`, `VideoCapture(1)` и т.д.

В GUI:
1. Включите камеру.
2. Нажмите **↻** рядом с выпадающим списком «Камера».
3. Выберите камеру и нажмите **▶ Start**.

Под Windows используется backend **DirectShow** — он быстрее MSMF для вебок.

## 2. GoPro

### Вариант A: USB-режим «Webcam» (рекомендуется, проще)

Современные GoPro (HERO8+ Black, HERO9, HERO10, HERO11, HERO12) умеют работать
как обычная UVC-вебкамера по USB-C:

1. Включите камеру, **вытащите батарею**, вставьте обратно (GoPro quirk).
2. Подключите по USB-C к ПК.
3. При появлении меню на экране GoPro выберите **«GoPro Webcam»**.
4. В Windows она появится как обычная UVC-камера.

### Вариант B: WiFi-стрим (без провода)

GoPro умеет отдавать RTSP-стрим через мобильное приложение **GoPro Quik**:

1. Включите WiFi на GoPro (свайп вниз → Preferences → Wireless Connections).
2. Подключите компьютер к WiFi-сети GoPro (SSID вида `GP…-…`).
3. В **GoPro Quik** на смартфоне включите «Live Preview»/«Webcam».
4. В приложении в поле **«URL (опц.)»** введите:
   ```
   rtsp://10.5.5.9:8554/live
   ```
   (IP `10.5.5.9` — дефолт GoPro; проверьте через Quik)
5. Нажмите **▶ Start**.

### OpenGoPro SDK (продвинутый вариант)

Если хотите управлять камерой программно (запись/старт/ISO/выдержка) — есть
официальный [OpenGoPro SDK](https://gopro.github.io/OpenGoPro/) на Python,
который можно интегрировать в качестве отдельного backend'а.

## 3. Промышленные камеры

### USB3 Vision / USB2 Vision (Basler, IDS uEye, FLIR/Teledyne, The Imaging Source)

1. Установите **драйвер производителя** (он создаёт UVC-совместимое устройство
   или свой backend).
2. В большинстве случаев камера появится в системе как обычная UVC-камера.
3. В DMQC выберите её индекс в выпадающем списке.

> Если у камеры проприетарный интерфейс (например, **uEye Cockpit** для IDS),
> используйте их ПО для «проброса» RTSP/HTTP стрима, либо библиотеку
> **Aravis** для GigE (см. ниже) — DMQC подключится по URL.

### GigE Vision (Baumer, Allied Vision, Basler ace, FLIR Blackfly S)

Чистый GigE Vision напрямую OpenCV не читает. Варианты:

- **Снимите RTSP-стрим с контроллера** камеры (через `cvlc`, `ffmpeg` или ПО
  производителя) и передайте URL в DMQC:
  ```
  rtsp://192.168.1.21:8554/mystream
  ```
- Используйте **[Aravis](https://github.com/AravisProject/aravis)** + GStreamer —
  `v4l2` совместимый backend, тогда камера видна через V4L2.

### Промышленные камеры с HDMI/Ethernet выходом (Mokose, AHD)

Если камера отдаёт **RTSP / HTTP-MJPEG / ONVIF** — достаточно ввести URL в GUI.

## 4. Смартфон как IP-камера (дешёвая альтернатива)

**Android — IP Webcam** (отличное бесплатное приложение):

1. Установите [IP Webcam](https://play.google.com/store/apps/details?id=com.pas.webcam).
2. Запустите сервер, откройте «Video renderer → Java».
3. Скопируйте URL вида `http://192.168.1.10:8080/video`.
4. Вставьте в DMQC.

**iOS — EpocCam / Iriun Webcam** — работают как UVC или RTSP.

## Чеклист подключения

| Симптом | Решение |
|---|---|
| Камера не появилась в списке | Закройте Skype/Zoom/Teams, нажмите ↻ |
| Чёрный экран | Смените backend (DirectShow ↔ MSMF) — DMQC пробует оба |
| Лагает / фризы | Уменьшите разрешение и FPS, отключите автофокус камеры |
| Декод не находит код | Увеличьте разрешение; проверьте ROI; настройте фокус вручную |
| RTSP-стрим рвётся | Проверьте WiFi сигнал, переключитесь на провод |

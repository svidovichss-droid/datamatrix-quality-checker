# Методология оценки качества

Этот документ описывает, **что именно** считает грейдер и **почему** результат
можно использовать для скрининга на конвейере.

## Источник стандарта

Полная верификация DataMatrix описана в:
- **ISO/IEC 15415** — 2D-символы (лазерная/термо-печать, этикетки)
- **AIM DPM-1-2006** — Direct Part Marking (нанесение на металл/пластик)
- **ISO/IEC 16022** — спецификация символа DataMatrix ECC200
- **GS1 General Specifications** — для логистических кодов

Всего 7–9 параметров. Наш грейдер вычисляет **6 ключевых**, приводя их к
диапазону `[0, 1]` (где 1 — идеал), и сводит во взвешенную оценку.

## Считаемые параметры

### 1. Decodability (30%)

**Что это.** Надёжность чтения: насколько стабильно код декодируется
N кадров подряд.

**Как считаем.**
```
decodability = 0.7 * (success_streak / required) + 0.3 * (success_streak / total_attempts)
```

- `success_streak` — количество подряд успешных чтений одного и того же кода.
- `required` — настраивается (`stable_reads_required`, по умолчанию 3).
- `total_attempts` — все кадры с момента сброса.

**Почему так.** Серийный DataMatrix на конвейере должен читаться
**каждый кадр**, пока объект в кадре. Любой «флик» между кадрами — сигнал
о нестабильной печати или расфокусировке.

### 2. Contrast (20%)

**Что это.** Отношение `(max - min) / 255` по яркости в ROI.

**Как считаем.** `minMaxLoc` по grayscale ROI.

**Интерпретация.**
- `0.6–0.9` — отлично, печать контрастная.
- `0.4–0.6` — приемлемо.
- `< 0.4` — печать выцвела, или слабая подсветка.

### 3. Modulation (15%)

**Что это.** Резкость границы между чёрным и белым модулем.
Нерезкая печать → «мыло» по краям → плохая считываемость сканером.

**Как считаем.** `var(Laplacian(ROI))` + логистическая нормализация.
Типичный диапазон на реальных этикетках: 50–2000.

**Интерпретация.** Высокий var = чёткие края, низкий = размытие/мыло/расфокус.

### 4. Print Growth (15%)

**Что это.** Отклонение реальной доли чёрных модулей от 50%.

**Как считаем.** Otsu → бинаризация → `mean(bw == 0)`. Идеал 0.5.
Допуск ±0.15 → score ≈ 1.0. Дальше линейно падает до 0.

**Почему важно.**
- Слишком **много чёрного** → «заливка» → код может сливаться в пятно.
- Слишком **мало чёрного** → «прострел» → точки исчезают.

### 5. Axial Non-Uniformity (10%)

**Что это.** Насколько ровная регулярная сетка модулей.
Сильное растяжение/сжатие по одной оси = низкое качество.

**Как считаем.** FFT-анализ горизонтальной и вертикальной проекций +
нормализованная автокорреляция. Острые пики = регулярная сетка.

**Упрощение.** Точная ANU требует знания шаблона L-образной «лесенки»
DataMatrix; в скрининговом грейдере мы оцениваем регулярность проекций.

### 6. Fixed Pattern Damage (10%)

**Что это.** Доля повреждённых ячеек тайла (царапины, кляксы, разрывы).

**Как считаем.** `connectedComponentsWithStats` на бинарном ROI.
Маленькие компоненты (<20 px) — шум/разрывы → минус score.
Слишком большие — заливка → тоже минус.

## Итоговый Grade

```
score = round( 100 * Σ(metric_i * weight_i) )
```

| Score | Grade | Цвет |
|-------|-------|------|
| 90–100 | A | 🟢 зелёный |
| 75–89  | B | 🔵 синий |
| 60–74  | C | 🟡 жёлтый |
| 40–59  | D | 🟠 оранжевый |
| 0–39   | F | 🔴 красный |

## Что грейдер НЕ заменяет

Это **скрининговый** инструмент, не сертифицированный верификатор:

- **Не** определяет Quiet Zone violations с микронной точностью.
- **Не** строит полный Reference Decode Algorithm (стандартная процедура
  сравнения с эталонной матрицей).
- **Не** сертифицирован по ISO 15415 и не даёт юридической силы.

Для финального аудита печати используйте:
- **Cognex DataMan + In-Sight Explorer** (промышленный)
- **Omron / Microscan / Keyence** верификаторы
- Калиброванные 2D Imager + специализированный софт (MV422, Symbol Reader)

## Использование в production

1. **Сначала прогоните эталон** (заведомо хороший код) — настройте экспозицию
   камеры, фокус, угол. Запишите типичный score эталона.
2. **Калибруйте пороги** `min_grade` под ваш продукт. Для строгих применений
   (фарма) — `A`, для логистики — `C`.
3. **Мониторьте тренд** в `logs/results.csv`. Если средний score падает
   за смену — пора менять расходники (термоголовку, красящую ленту).
4. **Сохраняйте скриншоты** отбраковки — это материал для разбора причин.
